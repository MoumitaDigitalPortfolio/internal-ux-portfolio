Solstice · Enterprise analytics

Tableau → Power BI

Moving dashboards to a new platform without making people learn everything again.

Solstice was moving more than 10 enterprise dashboards from Tableau to Power BI. The job was not simply to recreate the old screens. It was an opportunity to make the reporting experience cleaner, more consistent, and easier to scan—while keeping familiar workflows intact.

Project snapshot

Product Designer

The challenge

The dashboards worked. The experience needed attention.

The existing Tableau dashboards contained important information and supported established reporting workflows. But layouts, chart styles, spacing, and navigation had evolved differently over time. Moving to Power BI created a chance to bring those pieces together.

There was one important balance to maintain: improve the experience without making regular users feel like they were starting from scratch. Familiar information needed to stay familiar, even when the interface around it changed.

Design approach

We were building a dashboard system, not redesigning screens one by one.

Instead of treating every dashboard as a separate design problem, I looked for patterns that could work across the reporting ecosystem. The goal was to make dashboards feel related, predictable, and easier to understand at a glance.

01

Create a familiar structure

Important information stayed in familiar places, while grids, spacing, and layouts became more consistent.

02

Make key information easier to find

KPIs came first, followed by trends and deeper detail, giving users a clearer path through the data.

03

Keep interactions predictable

Filters, slicers, drilldowns, and navigation followed familiar patterns across dashboards.

04

Build for the dashboards still to come

Reusable design rules gave future dashboard teams a stronger and faster starting point.

Visual design system

A shared visual language for every type of dashboard.

Different dashboards needed different visual emphasis. Executive reporting, operational tracking, and detailed data tables do not all behave in the same way. The system provided a consistent foundation while allowing each dashboard type to use the right visual treatment.

Enterprise Data Table Theme · JSON

{
  "name": "Enterprise Data Table Theme",
  "visualStyles": {
    "tableEx": {
      "*": {
        "grid": [{
          "gridVertical": true,
          "gridVerticalColor": {
            "solid": { "color": "#D2D2D2" }
          },
          "gridHorizontal": true,
          "outlineColor": {
            "solid": { "color": "#674BE2" }
          }
        }],
        "columnHeaders": [{
          "fontColor": { "solid": { "color": "#FFFFFF" } },
          "backColor": { "solid": { "color": "#323130" } }
        }]
      }
    }
  }
}

The JSON theme turned design decisions into reusable Power BI standards. Instead of manually styling every table, chart, and dashboard, teams could begin with a consistent visual foundation and adapt it to the reporting context.
